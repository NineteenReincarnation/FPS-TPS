# FPS & TPS

[简体中文](README.md) | **English**

Displays FPS and TPS in RimWorld **1.7**'s native bottom-right UI, with configurable display settings.

Author: **anno** · Mod ID: `anno.fpsandtps`

## Installation

1. Download the complete mod package from [Releases](https://github.com/NineteenReincarnation/FPS-TPS/releases/latest) and extract the `FPS&TPS` folder into `RimWorld/Mods`.
2. Install and enable [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) and this mod, then restart the game.

Settings: **Options → Mod settings → FPS & TPS**.
