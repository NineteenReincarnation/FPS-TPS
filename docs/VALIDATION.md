## 实现范围

使用游戏公开的 GameComponentOnGUI 和 WindowLayer.GameUI。正式代码没有 tick/update 重写或任何运行时补丁。显示放在游戏已经完成布局的右下角信息栈上方，通过公开的 LetterStack.LastTopY 避开日期、天气和信件，无需反射私有布局字段。

TPS 改为与原版计数器一致的 `min(1000 / MeanTickTime, 60 * TickRateMultiplier)`，首次、变速及暂停状态变化立即刷新。它是处理速度估计值，不再是旧版按真实时间窗口累计的 tick 差值。常规刷新间隔控制稳定状态下的读取和格式化频率。

经过 100,000 次预热、2,000,000 次 Release 调用，原生 TPS 计算与未变化文本缓存均新增 0 字节托管分配。本次微基准分别约 17.43 ns 和 20.76 ns/次。该结果不包含游戏渲染，不能视为整场游戏零开销。

## 复现与限制

先运行 Build.ps1 部署，再运行 Tests/Run-RuntimeSmoke.ps1。运行时脚本使用游戏自带 Headless/QuitAfterBoot 和隔离配置，不修改玩家配置；临时测试 DLL 在结束后移出安装目录。测试启动配置会标记已安装 DLC 为已知，从而保持 Core-only 的测试环境。

尚未进行像素级或人工视觉验收，也未进行大型殖民地长时间性能对照。第三方全面替换 UI 的兼容性仍需对应实测。
