## 可复现命令

```powershell
./Build.ps1 -DeployPath 'D:\Steam\steamapps\common\RimWorld\Mods\FPS&TPS'
./Tests/Run-RuntimeSmoke.ps1
```

运行时脚本启动游戏自带的 **`-Headless -QuitAfterBoot`**，通过独立测试 DLL 调用游戏 API 验证，再自动将该 DLL 移出安装目录并保留在隔离测试目录。测试脚本在已有游戏运行时拒绝执行，避免影响玩家会话。测试源码在 `Tests/RuntimeSmoke/`；测试报告在 `artifacts/`，完整本地日志和隔离配置在 `.test-data/`，均不上传。
