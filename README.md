# FPS & TPS

**简体中文** | [English](README.en.md)

在 RimWorld **1.7** 右下角原生 UI 中显示 FPS 和 TPS，并提供显示设置。

作者：**anno** · Mod ID：`anno.fpsandtps`

## 安装

1. 从 [Releases](https://github.com/NineteenReincarnation/FPS-TPS/releases/latest) 下载完整 Mod 安装包，将 `FPS&TPS` 文件夹解压到 `RimWorld/Mods`。
2. 安装并启用 [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077) 和本 Mod，然后重启游戏。

设置位置：**选项 → Mod 设置 → FPS & TPS**。
